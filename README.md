# SUPER PARCEL LOGISTICS

Official website and direct booking portal for **Super Parcel Logistics**, providing commercial road, rail, and air freight transportation coordinating across strategic commercial trade corridors.
---

## Core Features
- **Multimodal Freight Portfolio:** Balanced presentation of Road (30%), Rail (25%), Air (20%), and Cargo/Warehouse Operations (25%).
- **Direct Dispatch WhatsApp Integration:** Client-side rate and cargo enquiry generator linking directly to +91 8217696321 with bot honeypot and rate-limiting.
- **Form-Focused Enquiry Page:** Clean, symmetric, distraction-free dispatch desk.
- **Light & Dark Mode:** Application-wide theme system with warm ivory Light Mode, industrial charcoal Dark Mode, FOUC prevention, system preference detection, and persistent theme toggle.
- **Production-Hardened:** Clean TypeScript types, zero lint warnings, fast Vite build, accessible WCAG AA standards, and complete SEO metadata.

---

## Tech Stack
- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS + custom industrial design tokens
- **Routing:** React Router v7
- **Icons:** Lucide React
- **Build Tool:** Vite 8
